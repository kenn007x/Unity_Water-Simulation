# WeatherVR 🌤️

A Virtual Reality (VR) weather simulation project designed for immersive atmospheric experiences.

## 📌 Features
- **Dynamic Weather System:** Real-time simulation of various weather conditions (rain, fog, day/night).
- **VR Support:** Optimized for Virtual Reality interaction and deployment.


## 🛠️ Development Environment
- **Engine:** Unity,MQTT,ArduinoIDE
- **Platform:** Android / Meta Quest

## 🔌 Hardware Integration (ESP32)

This VR project interfaces with an ESP32 microcontroller to fetch physical environment data (e.g., temperature, humidity, rain sensors).

- **ESP32 Source Code:** (https://github.com/kenn007x/ESP32_WaterSimulation)

## 🚀 Getting Started
1. Clone or download this repository to your local machine.
2. Open Unity Hub, click **Add project from disk**, and select this project folder.
3. Open the project using the matching Unity version.
